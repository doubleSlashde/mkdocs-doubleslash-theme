# Exportierte Diagramme (Projektmanagement)

Hier liegen typischerweise **PNG/SVG** aus dem PlantUML-Gantt-Export, z. B. `projektplan-gantt.png`. Im Template werden diese Dateien oft **nicht** ins Repository übernommen; sie entstehen lokal oder in der CI nach dem Export (Export-Tooling im Blueprint-Bundle bzw. `tools/md-gantt-export`).

Siehe auch [Diagramm-Export (Projektmanagement)](../diagramm-export/README.md).
