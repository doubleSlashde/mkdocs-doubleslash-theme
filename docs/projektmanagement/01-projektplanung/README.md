# 01 – Projektplanung

In diesem Modul wird die **Planung und Steuerung des Projekts** abgebildet: Projektplan,
PI-Planung (Program Increment), Epic-Planung sowie PI-Reviews und -Commitments.

## Inhalte & Verweise

| Seite / Unterpunkt | Beschreibung |
|--------------------|--------------|
| `Projektplan.md` | Gesamtprojektplan (Gantt, Phasen, Meilensteine) |
| `rollout-template-bestandsprojekte.md` | Rollout-Strategie für ReCode Blueprint in Bestandsprojekten |
| `pi-template/pi-review-report.md` | Vorlagen und Listen für Program Increments; Fortschritt und PI-Reviews |
| `pi-commitment/ablage-jahr-quartal/pi-commitment.md` | PI-Commitments pro Jahr/Quartal (Ablage) |

## Unterstützende Tools

- **PI-Dashboard** (siehe [12-Dashboard & Tools](../12-dashboard-und-tools/README.md)) –
  Fortschritt und KPIs pro Program Increment.

## Cursor Skills (dieser Bereich)

| Skill                           | Kurzbeschreibung                                                                                                                                                                 |
|---------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **projektplan-befuellen**       | Projektplan (`projektplan.md`): PlantUML-Gantt, Phasen- und Meilenstein-Tabellen; Quellen Repo/Datei/Chat/optional Jira; Freigabe vor dem Schreiben; danach Rückfrage Bildexport |
| **projektplan-diagramm-export** | Gantt → PNG/SVG nach `docs/projektmanagement/images/`; nach Ja aus projektplan-befuellen oder direkt                                                                             |
| **plantuml-doubleslash-theme**  | PlantUML-Blöcke: doubleSlash- **umltheme**                                                                                                                                       |
| **pi-commitment**               | PI-Commitment-Dokumentation aus Jira befüllen (Scope, Meilensteine, Abhängigkeiten, Risiken)                                                                                     |
| **ticket-creator**              | Epics, User Stories, Defects im Kundenjira anlegen (MCP)                                                                                                                         |

**Hinweis:** On-/Offboarding-Tickets in Jira (Epic-Suche, Akzeptanzkriterien aus der On-Offboarding-Doku) werden mit **onboarding-ticket** bzw. **offboarding-ticket** geführt – siehe [02 – Projektorganisation](../02-projektorganisation/README.md).
