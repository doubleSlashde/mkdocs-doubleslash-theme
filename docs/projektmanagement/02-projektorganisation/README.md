# 02 – Projektorganisation

Hier liegt die **operative Projektorganisation**: Definition of Ready/Done/Estimate,
Prozess-Übersichten, Teamorganisation, Meeting-Struktur, Buchungsrichtlinien und Maßnahmen.

## Cursor Skills (dieser Bereich)

| Skill | Kurzbeschreibung |
|-------|------------------|
| **doe-checker** | Epics gegen DoE prüfen (Jira/MCP); Kriterien in `doe.md` |
| **dor-checker** | Tickets/Sprint gegen DoR prüfen (Jira/MCP); Kriterien in `dor.md` |
| **massnahmenliste-anlegen** | `massnahmenliste.md` minimal: Satz + Tabelle mit **einer Beispieldaten-Zeile** |
| **massnahmenliste-sync** | Maßnahmen mit `massnahmenliste.md` abgleichen |
| **projektuebersicht-befuellen** | Projektübersicht (`projektuebersicht.md`): zuerst verlinkte Repo-`.md`-Ziele auf Leere/Vorlage prüfen (sonst Blockade-Hinweis); Repo + optional `projektuebersicht-quelle.md`; Lücken gezielt abfragen |
| **onboarding-ticket** | On-Offboarding-Dokumentation: Onboarding-Epic, Ticket `Onboarding: [Name]`, hierarchische Akzeptanzkriterien (Jira/MCP) |
| **offboarding-ticket** | Gleiche Doku-Quelle: Offboarding-Epic, Ticket `Offboarding: [Name]`, invertierte Akzeptanzkriterien (Jira/MCP) |

**Alle Skills auf einen Blick** in der Cursor Skills – Übersicht.

**Optional:** Eckdaten für die Übersicht gebündelt in `projektuebersicht-quelle.md` (gleicher Ordner) – siehe Skill **projektuebersicht-befuellen**.
