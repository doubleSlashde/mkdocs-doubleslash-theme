# CoC-Protokoll (formell) – PDF

Hier liegt das **generierte PDF** der formellen Marp-Fassung des Change-of-Control-Protokolls.

| Datei | Bedeutung |
|-------|-----------|
| **coc-Protokoll-formell-template.pdf** | Export aus den Marp-Slides (nach Befüllung und Build) |

**Quellen, Theme und Build** (npm, Marp) liegen im vollständigen Blueprint-Bundle unter `tools/coc-protokoll-marp/` – **nicht** zwingend in jedem Projekt-Repository. Das befüllbare Protokoll ist **`coc-protokoll.md`** (übergeordnetes Verzeichnis); zur Transition-Phase siehe [10 – Transition-In](../README.md).
