# Diagramm-Export (Projektmanagement)

Von **PlantUML-Gantt-Exporten** erzeugte PNG/SVG-Dateien werden typischerweise unter **[images](../images/README.md)** abgelegt. (Das Export-Skript liegt im Blueprint-Bundle bzw. unter `tools/md-gantt-export` im Projekt-Template.) Dieser Ordner dient der Navigation und Verknüpfung; gebündelte Exporte liegen bei Bedarf zusätzlich hier.
