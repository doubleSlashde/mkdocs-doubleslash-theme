# Architektur

Hier dokumentieren Sie die Architektur des Projekts – von der fachlichen Einordnung bis zu technischen Sichten und Schnittstellen.

**Projektspace:** Im Template liegt zunächst nur diese Datei. Unterordner und konkrete Artefakte entstehen im Projektverlauf und werden mit dem **Blueprint Architecture Toolkit (BAT) für die Architektur** angelegt.
